# Revia — Marketing Site

Coming-soon landing for **Revia**, an app for creating spatial memories. Users craft visual memory experiences and attach them to physical objects, scanning the object later to revisit the moment through AR.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm run start
```
